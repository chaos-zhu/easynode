# Windows / macOS 本地开发

桌面端与移动端共用 `native` 工程、Material 3、Riverpod 和登录协议。
通过操作系统选择桌面页面，不根据窗口宽度切换到移动端。实例列表读取服务端目录，
终端页支持本地 SSH、SFTP、状态监控及嵌入式 Docker、AI；凭据、脚本、批量指令、
定时任务和系统设置使用独立桌面布局；文件对传复用双 SFTP 面板，RDP 使用随应用
打包的 FreeRDP 引擎，每个连接显示为 EasyNode 独立窗口。
只有用户打开连接或对应辅助面板后才建立连接；全局 AI 使用桌面抽屉，首次打开前
不建立 AI 会话连接，不运行移动端更新检查。

## 运行

在 `native/` 下执行：

```sh
flutter pub get
flutter run -d macos
```

Windows 必须在 Windows 主机上安装 Flutter 和 Visual Studio 的
“使用 C++ 的桌面开发”工具链，再执行：

```powershell
flutter pub get
flutter run -d windows
flutter build windows --debug
```

窗口默认 1280 × 800，最小内容尺寸 900 × 640，保留系统标题栏。
macOS 标题栏同步应用的明暗模式与左侧菜单栏背景色（主题 `card`），保留系统窗口按钮。
切换配色，以及跟随系统模式下的明暗变化，均同步更新原生窗口。
原生桥接变更需停止后重新构建并运行应用，仅热重载或热重启不会安装新的窗口处理逻辑。
Windows 的最小尺寸按当前屏幕 DPI 换算，并计入系统窗口边框。

## Apple 依赖与签名

- 当前 HarmonyOS `package_info_plus` 分支的 macOS `Package.swift` 缺少逗号，
  因此项目暂时关闭 Swift Package Manager，使用现有 iOS/macOS Podfile。
  上游修复后再重新验证和开启；不修改全局 Flutter 配置或本机依赖缓存。
- macOS Debug/Profile 使用非沙箱本地构建和系统加密登录 Keychain，
  Runner 使用 `Apple Development` 签名，开发团队为 `5BQLRCF2QW`。本机须安装
  对应的有效证书和私钥；其他开发者可在 Xcode 的 Runner target 中选择自己的团队。
  稳定开发签名用于保持重新构建后的 Keychain 访问身份，不再使用 ad-hoc 签名。
  旧 ad-hoc 构建创建的记录仍可能需要一次性重新授权。此配置仅用于开发。
  Debug/Profile 同时声明用户选择文件的读写权限，`file_picker` 即使在非沙箱模式下
  也会先校验此声明；修改 entitlement 后须停止并重新构建运行，热重载不会生效。
- Release 保留 App Sandbox、网络客户端权限和 Keychain 权限，使用数据保护
  Keychain；允许读写用户在文件选择器中主动选择的文件或目录，用于私钥导入、终端导出
  和 SFTP 上传下载。
  正式分发前需要配置开发团队、稳定 Bundle ID 和签名。
  Debug/Profile 与 Release 的 Keychain 后端不同，本阶段不迁移开发会话。
- 所有模式都通过 `flutter_secure_storage` 存储秘密；存储失败时提示重试，
  不降级到 SharedPreferences 或明文文件。

## 登录与状态边界

- 登录复用服务端地址、RSA 密码加密、可选 MFA 和 3/7/30 天有效期。
  HTTP 必须确认风险，自签名 HTTPS 证书必须确认 SHA-256 指纹；指纹变化重新确认。
- 每次登录使用独立内存 cookie，失败后丢弃。成功后才把 cookie、deviceId、token
  写入系统安全存储，token 最后写入，作为会话提交标志。
- 只支持一个活跃账号。保存密码按服务地址和用户名区分；历史账号仅保存元信息。
- 退出时关闭旧 API 客户端并清理会话，新的登录提交等待旧清理完成。
  桌面主动退出若清理失败则留在原界面提示重试；保存的密码和历史账号保留，
  可在登录历史中删除。
- 冷启动用轻量鉴权接口确认会话。临时断网保留凭据并允许重连，鉴权失效回到登录。
- 会话 cookie 在 `SecureAppStorage` 中首次读取后仅保留一份内存缓存，REST、AI 和
  Docker 客户端共用。登录和服务端 cookie 更新先成功持久化再更新缓存，相同 cookie
  不重复写入；退出立即清空缓存，再删除持久化记录。网络请求不逐次访问 Keychain。
  成功恢复会话时不预读保存的密码，登录页出现时再按已有账号逻辑读取。
- 桌面壳不挂载移动端业务壳及其数据初始化 provider。实例列表通过独立的
  `desktopServerCatalogProvider` 复用现有 `ServerRepository.fetchCatalog()`，
  读取主机、分组与服务端排序。默认使用 Web 的分组表格布局，展示名称、用户名、
  主机、端口、认证方式和标签，右侧固定操作列；支持搜索、分组折叠和复选。
  已接入单实例新增、编辑与删除、列表设置、分组管理与排序；连接进入桌面终端，
  批量操作与导入仍仅提示“功能开发中”。加载失败可重试。
- 列表设置参照 Web 的 600px 双页签弹窗，支持十个字段开关、分组展示与平铺展示。
  `desktopServerListConfigProvider` 通过独立 Repository 读写 `/server-list-config`，
  与 Web 共用服务端列表偏好；移动端不订阅该 provider，保留原有展示逻辑。
  弹窗编辑草稿，取消不修改列表，保存成功后才应用；失败保留草稿供重试。
  设置读取失败时目录仍可使用，弹窗禁用保存，避免用默认值覆盖服务端偏好。
  隐藏选择列时清空勾选，操作列始终保留；平铺模式读取服务端全局顺序，不修改排序。
  可选显示代理类型、到期日期及控制台 URL，控制台点击仍为开发中占位。
- 分组管理参照 Web 的 640px 弹窗，展示名称、默认标记、实例数量及编辑/删除操作。
  支持新增、改名和删除；默认分组可改名、不可删除。删除前确认并说明实例将由服务端
  移入默认分组。名称去除首尾空白且不可为空，写入失败保留输入供重试。
  使用独立 `ServerGroupRepository` 调用 Web 的 `/group` 接口，成功后只刷新桌面目录。
- 分组与实例均支持拖动排序，草稿取消不写入服务端，保存时复用 `/host-order` 和 revision。
  分组管理提交 `groups`；实例分组视图提交 `groupItems`，平铺视图提交 `flat`，
  各自保留其他维度的顺序。进入实例排序时清空搜索与勾选，隐藏业务操作；整行可拖动，
  接近滚动区域边缘时自动滚动，列展示继续沿用列表设置。普通错误保留草稿供重试；
  服务端返回 409 时重新获取目录并提示再次调整。移动端页面和排序状态均未接入这些改动。
- 新增和编辑参照 Web 的 680px 双列表单，复用现有 `ServerFormData` 与 Repository，
  通过 `/host-save` 保存，认证字段沿用 RSA 包装临时密钥与 AES 加密协议。
  编辑时不读取已保存的密码或私钥；同一认证方式留空保留原值，更换认证方式需填写
  新秘密或选择凭据。支持本地私钥文件、到期日期、标签与折叠的代理等高级设置，
  RDP 和代理选择沿用服务端 Plus 授权；凭据、代理选项使用现有配置列表接口。
  单实例删除通过 `/host-remove`，提交前确认，失败留在弹窗内提示重试。
  管理弹窗使用 `DesktopManagementDialog` 配合统一过渡，保存中禁用输入和关闭。
  新增/编辑对齐 Web 的 680px 顶部弹窗、双列布局、44px 输入、圆形单选、
  矩形按钮和高级设置区域。`desktop_form_controls.dart` 提供桌面表单基础样式；
  `DesktopSelect` 与 `showDesktopPopover` 提供主题化下拉及日期浮层，支持悬停、
  选中标记、键盘和 Esc、点击外部关闭及淡入位移；跳板机多选保留选择顺序。
  写入后仅刷新桌面目录，不初始化移动端连接状态、不获取 SSH 连接参数。
- 实例列表工具栏操作固定靠右。工具栏及操作列的更多菜单统一使用
  `lib/core/ui/desktop_dropdown_menu.dart` 的 `DesktopDropdownMenu<T>`，
  参考 Element Plus 的紧凑菜单、主题描边、悬停高亮和危险操作样式。
  整体淡入缩放 200ms、收起 140ms，尊重系统减少动画设置；支持键盘选择、
  Esc 和点击外部关闭，空间不足时向上展开。此组件仅接入桌面实例列表。
- 侧栏顶部直接展示菜单，不展示品牌标题或折叠按钮。底部参照 Web 展示用户名和
  Plus 入口；点击用户名打开版本、主题、AI 助手、折叠和退出菜单，退出无需二次确认。
  版本入口展示当前版本及项目链接，AI 助手菜单切换 Native 助手可见性，
  Plus 入口直接进入系统设置的授权页。
- 侧栏展开宽度 174，折叠宽度 64。桌面弹窗统一使用
  `lib/core/ui/app_dialog.dart` 的 `showAppDialog<T>`，保留 `builder` 和返回值用法。
  入场为 260ms 淡入与 20px 位移，退场为 180ms；尊重系统减少动画设置。
  HTTP、证书、登录历史、删除确认、版本及 IP 限制弹窗已接入，移动端仍使用标准弹窗。
  `closeOnPressEscape` 默认 `true`，独立控制 Esc 关闭，与遮罩点击关闭
  `barrierDismissible` 分开设置；证书和 IP 限制弹窗显式设为 `false`。

## 桌面终端

- `lib/features/terminal/desktop/` 单独组织桌面界面。工作区拥有本地 SSH 会话，
  切换标签、分屏、平铺或左侧模块保留连接和终端缓冲；关闭标签和退出登录释放资源。
  支持左右/上下四分屏、标签与平铺布局、分屏或全局同步输入、重连和最近连接记录。
- 终端包含复制粘贴、选择菜单、正则/大小写/全词搜索、日志导出、链接打开、
  字号快捷键及应用内全屏；全屏扩展终端工作区，F11 切换、Esc 退出，不调用系统窗口全屏。
  状态面板复用 Native 监控服务，延迟从本机测量到 SSH 主机。
  多窗口为标签页与分屏，单窗口平铺所有 PTY，隐藏标签、状态侧栏和普通工具条；
  支持平铺区域拖动、单个终端放大及关闭，超过四个终端可切换横向排列。
  辅助面板和长指令区域支持拖动调整尺寸，窄窗口通过滚轮和触控板滚动保留桌面布局，
  桌面端隐藏滚动条。
- SFTP 复用 Native 直连服务，支持文件/目录上传下载、文本编辑、图片预览、
  新建、重命名、复制、移动、删除、压缩/解压、收藏、筛选、隐藏文件及列设置。
  SFTP 与 AI 互斥显示，隐藏不销毁已有面板、路径、传输或对话草稿。
  SFTP 工具栏及路径栏对齐 Web，搜索通过浮层展开；关闭按钮始终可见。
  每台主机保留传输队列、进度、取消和重试。收藏读写增加 REST 接口，数据与 Web 共用；
  需同步更新服务端才能新增或删除收藏。文件内容不经过服务端。
- Docker 复用现有服务端 WebSocket 协议与 Plus 限制，支持容器和批量操作、日志及
  进入容器；进入容器和 Compose 指令发往当前本地终端。
- AI 复用现有对话、模型、审批和历史界面，每个面板绑定一个本地 PTY；工具指令
  不参与同步输入。终端会话历史按主机隔离，模型/权限偏好与移动端全局 AI 分开保存。
  与 Web 一致，不在每轮对话附带完整终端画面，工具执行结果提供结构化上下文。
- 脚本库和长指令编辑器复用服务端脚本接口，支持分组、脚本增删改、Base64 和
  发送后执行选项。连接及脚本菜单读取服务端排序。
  底部长指令草稿在隐藏及切换布局后保留；平铺终端标题提供独立指令弹窗，
  草稿按 PTY 保留，发送仅面向该终端，发送按钮固定在右侧。
- 外观、语义高亮及行为设置与 Web 共用 `/terminal-settings` v3 文档，支持预览、
  内置/自定义配色、字体、图片背景及自定义高亮规则。桌面布局偏好本地单独保存。
  本轮不渲染 HTML/CSS 动态背景，编辑其他配置时保留 Web 的 HTML 主题定义。
- 不实现依赖服务端连接的会话挂起/恢复。SSH 主机指纹校验按本轮约定后置，
  当前连接仍沿用现有 Native 策略；HTTPS 证书确认不等同于 SSH 主机身份校验。

## 桌面管理模块

- 页面参照 Web 的工具栏、表格、分页、分组标签、表单和设置分栏组织。
  `desktop_management.dart` 统一管理控件，复用现有主题化弹窗、下拉和浮层，
  支持中英文、系统文字缩放与横向滚动。加载进度覆盖在内容上方，不挤动列表。
- 桌面主壳按需挂载各模块，切换后保留已访问页面的状态；系统设置内的七个页签
  同样保留未提交的表单草稿。移动端继续使用现有页面。
- 凭据管理支持增删改、密码和私钥认证、本地私钥文件、加密 PEM 解密与 OpenSSH
  密码。默认凭据不可删除；编辑时秘密留空保留服务端原值。继续复用既有
  SettingsRepository 的加密写入协议，不把秘密写入本地普通配置。
- 脚本库支持搜索、分页、批量删除、内置只读脚本、直接发送/Base64、分组管理和
  组内排序；Plus 导入支持多份 JSON 或每行一条指令，导出不包含内置脚本与 ID。
  终端脚本区和管理页共用脚本目录、编辑器与分组弹窗，保存后同步刷新。
- 批量指令使用服务端 `/onekey/` Socket.IO 执行，鉴权沿用 token、cookie 和
  HTTPS 证书信任；不创建本地 SSH。支持多实例、脚本导入、默认 120 秒超时、
  实时输出、停止单实例/整批，以及 `/onekey` 历史分页、分块输出和删除。
- 定时任务使用现有 `/scheduled-tasks` 接口，由服务端调度；关闭桌面端不会停止
  后续调度。支持 CRUD、启停、Cron/时区预设与手动输入、实例多选、内联/引用脚本、
  Base64、通知策略、立即运行、执行历史与清理。执行详情抽屉轮询运行状态，
  展示各实例 stdout/stderr、失败原因、耗时和截断提示，并可停止整批。
  桌面新增任务默认每天 02:00，移动端原有默认值不变。
- 系统设置包含账户与 MFA、登录会话与注销、IP/CIDR 访问控制、通知渠道与事件、
  代理节点、AI Provider/MCP/主机策略、Plus 激活与授权设备管理。
  通知配置覆盖邮箱（含自定义 SMTP）、Server 酱、Telegram、Webhook；保存前
  由服务端测试通知。AI 编辑保留未知配置及 Web 专属偏好，MCP 编辑不回写掩码秘密。
  更新账户或注销当前/全部会话后清理本地登录态；IP 规则排除当前来源时允许
  返回、加入当前 IP 或显式强制保存。
- 全局 AI 复用原有对话与审批功能，桌面使用右侧抽屉，首次打开后允许后台任务继续。
  终端 AI 继续绑定独立 PTY，移动端全局 AI 保持原来的默认布局与连接时机。

## 文件对传与远程桌面

文件对传左右浏览器复用 `DesktopSftpPanel`，各自持有独立 SFTP 会话；同一实例可在两侧
打开不同目录，也不会影响终端里的 SFTP。选中源文件后选择方向，确认预览即通过现有
`/file-transfer` Socket.IO 创建 Rsync 任务，沿用服务端 Plus 功能控制、传输选项和任务管理。
任务支持查看进度、取消、失败重试、删除和清空；切换菜单或关闭桌面端不取消服务端任务。
源服务器需能直连目标服务器，服务端当前文件对传执行路径不使用本地代理/跳板机。

远程桌面页使用 Web 的连接菜单与 150×150 会话卡片；实例列表中的 Windows 连接也进入此页。
每个实例启动独立的 EasyNode FreeRDP SDL3 窗口，点击已连接卡片唤起窗口，关闭卡片断开连接；
失败卡片可点击重试。分辨率、画质和剪贴板开关应用于新连接。切换菜单保留窗口，退出登录或
关闭 EasyNode 清理连接。使用本地 RDP 协议，不访问 guacd；支持直连和既有 HTTP/SOCKS、
SSH 跳板配置。主机身份检查沿用 FreeRDP 的证书确认 UI，不设置 `cert:ignore`。

需同步更新并重启服务端：新增 `POST /native/rdp-connection`，先检查 Plus 和 RDP 主机类型，
再使用现有 RSA 临时密钥 + AES-GCM 协议返回凭据与拓扑。旧 SSH 接口拒绝 RDP 主机取参。
密码只通过内存管道发送给引擎，不进入命令行、环境变量或 `.rdp` 文件。
FreeRDP 证书记录保存在 EasyNode Application Support 的 `rdp/` 下，与系统 SSH 钥匙串无关。

### 首次准备本地 RDP 引擎

引擎源代码固定为 FreeRDP 3.32.2 并校验 SHA-256。构建脚本添加 EasyNode 窗口控制与
内存凭据管道，保留上游图形、输入和剪贴板实现。引擎、动态库和开源许可证打包到应用中，
用户机器无需另外安装远程桌面客户端。

macOS（在 `native/` 下）：

```sh
brew install cmake ninja sdl3 sdl3_ttf openssl@3 cjson
bash tools/rdp/build-macos.sh
flutter run -d macos
```

这次开发机器已完成引擎构建；完整重新运行 Flutter 即可由 Xcode 嵌入，hot reload 不会复制
