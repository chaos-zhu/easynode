Terminal toolbar icons reuse the Web iconfont referenced in web/index.html. Other icons are from @element-plus/icons-vue 2.3.1 (MIT), as used by Web. Stored locally for offline rendering.

The remote desktop empty-state illustrations reuse Element Plus 2.11.4 img-empty.vue with its light/dark palettes, rendered to static SVGs. Monitor and List reuse @element-plus/icons-vue, like the other Element icons. Element Plus is MIT licensed; see element-plus-LICENSE.
